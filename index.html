Preparación

Activando los Agentes:
Claude & Perplexity

Instrucción Clave:

Crea la carpeta 'mi-escape-room' y el archivo 'insights-cliente.txt' para Claude MCP.

Fase 1: Awareness

Producto: Carousel de Instagram sobre los problemas del cliente.

Prompt para Perplexity:

"¿Cuáles son los 3 problemas más recurrentes que mi cliente ideal enfrenta en [tu nicho]?"

Fase 2: Consideration

Producto: Infografía de análisis competitivo.

Prompt para Gemini (Gem 'Analista Competitivo'):

"Analiza a [Competidor 1] y [Competidor 2]. Sugiere 2 ventajas para mi [producto/servicio]."

Fase 3: Decision

Producto: Diseño de Propuesta de Valor.

Prompt para Grok (basado en Claude):

"Genera 3 propuestas de valor disruptivas para [tu producto/servicio] con una promesa única."

Fase 4: Purchase

Producto: Carousel de manejo de objeciones.

Prompt para DeepSeek/NotebookLM:

"Simula objeción 'es caro'. ¿Cómo respondo con un script de cierre emocional consultando beneficios de NotebookLM?"

Fase 5: Retention

Producto: Infografía de mapa de fidelización.

Prompt para Gemini Advanced:

"Diseña 3 ideas de sorpresas personalizadas para clientes que han comprado [tu producto/servicio] hace 3 meses."

Fase 6: Advocacy

Producto: PDF con guía de testimonios.

Prompt para AI Studio:

"Genera prompts para una campaña de referidos en Instagram que incentive compartir experiencia a cambio de [recompensa]."

Fase 7: Mastery

Producto Final: Ecosistema de contenido completo.

Prompt para Orquestación (varios agentes):

"Crea una estrategia de contenido multiplataforma (IG, LinkedIn, Podcast) para 30 días sobre [tu tema central], con imágenes y audio."
